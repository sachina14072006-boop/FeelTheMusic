FeelTheMusic Deployment Guide
=============================

This is the short deployment summary for FeelTheMusic.


1. Deployed Services
--------------------

Frontend:
- React + Vite
- Folder: client/
- Platform: Vercel
- URL: https://client-beta-wheat-71.vercel.app

Backend:
- Node.js + Express
- Folder: server/
- Platform: Railway
- URL: https://feelthemusic-backend-production.up.railway.app

Database:
- MySQL
- Platform: Railway MySQL
- SQL files used: database/schema.sql and database/seed.sql

Emotion Service:
- Python + FastAPI + DeepFace
- Folder: emotion-service/
- Platform: Railway
- URL: https://feelthemusic-emotion-production.up.railway.app

GitHub:
https://github.com/sachina14072006-boop/FeelTheMusic.git


2. Main Changes Before Deployment
---------------------------------

- Cleaned the project and renamed it to FeelTheMusic.
- Added a production .gitignore.
- Added .env.example files.
- Created MySQL schema and seed data.
- Replaced localhost API URLs with Vite environment variables.
- Improved webcam video size and alignment.
- Randomized the first recommended track so webcam recommendations do not always start with the same song.
- Added Previous and Next controls to the recommendation music player.
- Added a Dockerfile for the emotion service so OpenCV works on Railway.


3. Important Environment Variables
----------------------------------

Frontend on Vercel:

VITE_API_URL=https://feelthemusic-backend-production.up.railway.app/api
VITE_EMOTION_API_URL=https://feelthemusic-emotion-production.up.railway.app

Backend on Railway:

DB_HOST=mysql.railway.internal
DB_USER=root
DB_PASSWORD=<stored in Railway>
DB_NAME=railway
JWT_SECRET=<stored in Railway>

Real secrets are stored only in Railway/Vercel, not in GitHub.


4. Deployment Commands Used
---------------------------

Backend:

railway up server --service feelthemusic-backend --path-as-root --detach --message "Deploy FeelTheMusic backend"

Emotion service:

railway up emotion-service --service feelthemusic-emotion --path-as-root --detach --message "Deploy FeelTheMusic emotion service"

Frontend:

vercel deploy client --prod --yes --scope sachina14072006-8002s-projects --build-env VITE_API_URL=https://feelthemusic-backend-production.up.railway.app/api --build-env VITE_EMOTION_API_URL=https://feelthemusic-emotion-production.up.railway.app


5. Database Setup
-----------------

The Railway MySQL database was initialized with:

- database/schema.sql
- database/seed.sql

These files create and populate users, songs, artists, emotions, playlists, ratings, mood logs, and recommendation mappings.


6. Important Fix
----------------

The emotion service first failed because OpenCV needed Linux runtime libraries.

Fix:
- Changed opencv-python to opencv-python-headless.
- Added emotion-service/Dockerfile.
- Installed required packages like libgl1, libglib2.0-0, libsm6, libxext6, and libxcb1.


7. Final Verification
---------------------

Backend:
- Returned: FeelTheMusic backend is running.

Emotion service:
- Returned: Emotion service is running.

Database:

9. Quick Troubleshooting
------------------------

Registration fails:
- Check Railway MySQL and backend DB variables.

Frontend API calls fail:
- Check VITE_API_URL on Vercel.

Emotion detection fails:
- Check camera permission and VITE_EMOTION_API_URL.

Emotion service returns 502:
- Check Railway logs for feelthemusic-emotion.
